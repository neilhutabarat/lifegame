# Rental Simulator by Oneilverse (v5.0 — Full Feature & Realistis Edition)

Game simulasi manajemen bisnis & kehidupan (*Life & Tycoon Simulator*) lengkap mulai **Januari 2020** di Indonesia.

## Cara Pasang ke GitHub Pages
1. Ekstrak seluruh isi file ZIP ini (`index.html`, `style.css`, `data.js`, `firebase-config.js`, `cloud.js`, `game.js`, `firestore.rules`, `README.md`).
2. Upload dan timpa seluruh file ke root repository GitHub kamu (`neilhutabarat/lifegame`).
3. Tekan **Ctrl + Shift + R** pada browser laptop/HP setelah deploy selesai.
